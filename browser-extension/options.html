Authenticator

Fills in the logins and 2FA codes saved in the Authenticator app on this PC. The extension talks only to the app, only while it is unlocked, and never over the internet.

How to use it

  • On a login page, click the Authenticator button in the toolbar and choose the login.
  • Or press Ctrl+Shift+U: it fills in the user name and password, or the 2FA code on the next page. To change the shortcut, open thorium://extensions/shortcuts (or chrome://extensions/shortcuts).
  • If Authenticator is locked, its window comes up and asks for your PIN first.
  • To save a login, use "Save login from this page" in the toolbar button after typing it on the page.
